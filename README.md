# 🎙️ AI-Powered Multilingual Speech-to-Speech Translation System

An intelligent multilingual Speech-to-Speech Translation System developed using Python and Streamlit.

This application enables users to:
- Convert speech to text
- Translate text into multiple languages
- Convert translated text back into speech
- Upload audio files or use microphone input
- Generate multilingual voice outputs

---

# 🚀 Features

✅ Speech-to-Text Transcription  
✅ Text-to-Text Translation  
✅ Speech-to-Speech Translation  
✅ Audio File Upload Support  
✅ Microphone Recording Support  
✅ Text Input Translation  
✅ Multilingual Support (100+ Languages)  
✅ Text-to-Speech Audio Generation  
✅ Interactive Streamlit Interface

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/PriyankaMittha/speech-to-speech-ai-translator.git
```

---

## Navigate to Project Folder

```bash
cd speech-to-speech-ai-translator
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

```bash
python -m streamlit run translate_speech.py
```
